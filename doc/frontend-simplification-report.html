Cross-cutting duplication

1. getFirstErrorMessage is copy-pasted into 8 files

The exact same 26-line form-error helper is redefined (non-exported) in every modal — both admin and public. There is no shared form-helpers module yet, so it just keeps getting pasted.

Where: -HotelModal.tsx:98, -RoomModal.tsx:64, -AnnouncementForm.tsx:49, -AssignModal.tsx:17, -BookingModal.tsx:72, -ComplaintModal.tsx:57, -RatingModal.tsx:37 (+1).

3. Currency formatting is duplicated and inconsistent

The ETB formatter is byte-identical in two files, and USD amounts are formatted ad-hoc with $(x / 100).toFixed(2) in ~6 more places. One helper module removes the drift.

Where: identical at bookings/index.tsx:67 and bookings/$bookingId.tsx:51; inline USD at walk-in/index.tsx:449,495,529, $bookingId.tsx:365, -OutsourceModal.tsx:81.

4. Booking status config + transition labels duplicated

A ~60-line statusConfig map and a transitionLabel map are defined in both the bookings list and the booking-detail page. They are identical except expired.icon (Ban vs XCircle) — a difference that looks accidental. The status-pill JSX is repeated too.

Where: bookings/index.tsx:177–240 and bookings/$bookingId.tsx:96–159; pill JSX at index.tsx:426, $bookingId.tsx:262.

5. Form text-field markup is pasted ~25 times

Inside -HotelModal alone the same label + input + error block is copy-pasted about 12 times (name, address, city, country, lat, lng, …), and -RoomModal / -BookingModal repeat the same shape. Each differs only by name, label, placeholder, type.

Where: -HotelModal.tsx:532–935, -RoomModal.tsx:366–483, -BookingModal.tsx:486–542.

6. Image-upload state/handlers duplicated between two modals

-HotelModal and -RoomModal share ~90% of their image plumbing: preview state, an object-URL revoke effect, a handleImageSelection handler, and the upload-or-clear branch in submit. About 250 LOC of near-identical code.

Where: -HotelModal.tsx:158–174, 371–433 ≈ -RoomModal.tsx:126–142, 221–291.

Nested ternaries (lint rule says avoid)

2. A spinner ternary whose branches are identical

The dark/light condition picks the same classes either way — it does nothing. This exact spinner (with the dead ternary) is pasted ~12 times across admin pages.

Where: bookings/index.tsx:384, $bookingId.tsx:205,649, hotels/$hotelId.tsx (×4), walk-in, rooms, complaints…

7. Triple-nested ternary for submit-button labels

Picking "Uploading… / Saving… / Update / Create" via nested ternaries is hard to read. A small named function with early returns is clearer and reused across the three modals.

Where: -HotelModal.tsx:1012, -RoomModal.tsx:643, admin/index.lazy.tsx:388.

8. Seven-level nested ternary for the payment banner

The booking payment banner walks through 7 statuses with a deeply nested ternary. A keyed lookup is flat, easy to extend, and removes the indentation pyramid.

Where: _authenticated/bookings.tsx:124–174.

9. Analytics cards repeat isDark class pairs and tooltips

All six analytics cards derive isDark and inline paired dark/light class strings; three of them contain a near-identical tooltip, and AnalyticsTrendChart has four nested isCurrency ? isDark ? … ternaries for colours. Centralising the theme decision removes the repetition and the nesting.

Where: tooltip at AnalyticsTrendChart.tsx:66, AnalyticsStatusBreakdown.tsx:66, AnalyticsOccupancyCard.tsx:199; colour ternaries at AnalyticsTrendChart.tsx:120–142.

Dead code & small cleanups

10. Redundant sync effects and a no-op filter (bookings list)

Two useEffects mirror URL search params into local state, then a useMemo re-filters by status that the server query already filtered. Reading search.* directly (and writing via navigate) removes the state, the effects, and the duplicate filter. This matches the pattern removed in commit 97d34ab.

Where: effects bookings/index.tsx:120–126; redundant filter :242–259 (status already applied at :133).

11. src/components/ui/chart.tsx is unused (~378 LOC)

Nothing imports ui/chart — the analytics views build directly on recharts. After a final reachability check it can be deleted outright.

Where: src/components/ui/chart.tsx (no consumers). Also unused: lib/distance.ts exports calculateDistanceMiles/formatDistanceMiles (referenced only in doc/).

12. Type-safety nits — (api as any) and error: any

Several calls cast the generated Convex api to any, defeating its types, and a few catches use error: any against the strict-mode guidance. There is already a typed getErrorMessage(unknown) helper in -OutsourceModal.tsx to reuse.

Where: bookings/index.tsx:129, walk-in/index.tsx:85,112,113, $bookingId.tsx:90, -OutsourceModal.tsx:65,76; error: any at walk-in/index.tsx:160,188.
